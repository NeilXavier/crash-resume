极速简历 v1.0.0 · Windows 免安装版
====================================

一、怎么使用
------------
1. 把压缩包完整解压到一个文件夹（不要只把 exe 拖出来，
   必须保留同目录下的 dist 文件夹）。
2. 双击「start.bat」，或直接双击「CrashResume.exe」。
3. 稍等一两秒，浏览器会自动打开：
   http://127.0.0.1:10087/
4. 使用期间不要关闭黑色命令行窗口；关闭窗口程序就会停止。

如果 10087 端口被其他软件占用，程序会自动尝试
10088～10107，请以窗口里显示的地址为准。


二、系统要求
------------
- Windows 10 / 11（64 位）
- Chrome、Edge、Firefox 等现代浏览器
- 不需要安装 Node.js、npm 或任何运行库
  （使用 Windows 自带的 .NET Framework 4.x）
- 不需要联网，导出也在本机完成


三、首次运行提示
----------------
本程序没有购买代码签名证书，Windows 可能弹出
「Windows 已保护你的电脑」：
  点「更多信息」→「仍要运行」即可。
部分杀毒软件也可能误报，因为这是一个本地静态服务器；
源码在 GitHub 上公开，可自行审查。


四、数据与隐私
--------------
- 简历、头像、草稿只保存在当前浏览器的 localStorage 中。
- 不会上传到任何服务器，没有统计、没有追踪。
- 清理浏览器站点数据，或换浏览器、换电脑，草稿会丢失，
  请及时导出 PNG / PDF 文件。
- 程序只监听本机 127.0.0.1，局域网内其他设备无法访问。


五、常见问题
------------
Q：双击后窗口一闪而过？
A：通常是解压不完整。请重新解压整个压缩包，
   确认 CrashResume.exe 和 dist 文件夹在同一个目录。

Q：浏览器没有自动打开？
A：手动在浏览器输入窗口里显示的地址，
   例如 http://127.0.0.1:10087/

Q：提示端口被占用？
A：程序会自动换端口，请使用窗口里显示的地址。
   也可以关闭占用 10087 端口的软件后重新启动。

Q：怎么停止程序？
A：直接关闭黑色的命令行窗口。

Q：怎么卸载？
A：关闭窗口后删除整个文件夹即可。
   如需清理浏览器数据，请在浏览器设置中删除
   127.0.0.1:10087 的站点数据。


六、其他平台
------------
本压缩包是 Windows 免安装版。macOS / Linux 用户可以
下载仓库源码，安装 Node.js 18+ 后按 README 运行：

  npm install
  npm run build:h5
  npm run serve:h5

源码与更新：https://github.com/NeilXavier/crash-resume
